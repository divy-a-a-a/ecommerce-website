# 🛒 E-Commerce Website

A responsive e-commerce website built using HTML, CSS, and JavaScript. The website allows users to sign up, log in, browse products, add products to the cart, and manage cart items.

## 🌐 Live Demo

[View Live Website](https://divy-a-a-a.github.io/ecommerce-website/)

## ✨ Features

- User Signup
- User Login and Logout
- Product Listing
- Products fetched dynamically using Fake Store API
- Add products to cart
- Remove products from cart
- Cart item count
- Responsive design
- Local Storage for user and cart data
- GitHub Pages deployment

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fake Store API
- Local Storage
- Git
- GitHub
- GitHub Pages

🚀 How to Run
Clone the repository:
git clone https://github.com/divy-a-a-a/ecommerce-website.git
Open the project folder:
cd ecommerce-website
Open index.html in your browser.

You can also use the Live Server extension in VS Code.
